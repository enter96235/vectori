# Vector Diag

Aplicacion de escritorio para diagnostico OBD-II. El programa de Windows
incluye la interfaz, el servidor local y los puentes J2534 de 32 y 64 bits.

## Descargar

El instalador de Windows se publica en [GitHub Releases](https://github.com/enter96235/vectori/releases).

## Compilar

Consulta [la guia de compilacion para Windows](./desktop/audi-tt-diagnostic/README.md)
para los requisitos, comandos de compilacion y alcance del diagnostico.

Los controladores del adaptador J2534 deben instalarse por separado desde el
fabricante. La aplicacion consulta datos OBD-II compatibles con el vehiculo y
el adaptador; no reemplaza un escaner OEM.
